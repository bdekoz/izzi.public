## Review pipeline changes

The page-102-style parameter panel is generated once by the shared review
pipeline and used by PDF export and PNG previews. It wraps declared numeric
annotations, reports SVG element counts and canvas size, and lists observed
stroke widths, paint opacity and colors. Small palettes additionally show
per-color opacity and stroke widths. Full values are retained in the PDF
sidecar and preview manifests. The panel uses Atkinson Hyperlegible, with
full-opacity dark text on white; art opacity is not inherited by the legend.
Page dimensions grow to fit the panel instead of cropping the artwork.

Paint inspection accounts for inline styles, inherited stroke/fill properties
and nested group opacity. It excludes text and definition-only shapes and
includes backgrounds. Values describe paint before transforms, masking,
filtering and compositing, not final pixel opacity or screen-space stroke
width. Stylesheet rules and gradient/pattern internals are flagged rather than
guessed. Original SVG output remains untouched; `review-svg/` contains labeled
copies with raster resources embedded. Preview cache policy 4 replaces the
old unlabeled previews and tracks pagination and labeled-copy hashes.

Coverage audit: all 624 plates receive a panel; 301 have existing declared
numeric settings and 323 expose observed SVG properties only. Eleven plates
have stylesheet/class-dependent paint, which is explicitly flagged as not
fully resolved. Exactly 54 canonical artwork files change in this batch:
227–259, 389–398, 401–403, 411–415 and 469–471. All other differences are
review wrappers/previews/PDF pages, not edits to generator artwork.

### How original page 513 was made

`examples/text-danmu-3.cc` constructs six runs on five lanes in a 1080 × 1920
document. Each character comes from a tiny hand-written SVG path repertoire,
scaled to a 72 px em; this is **not a font**. Unsupported characters use the
example's fallback crossed strokes. The paths inherit a 5-unit dark stroke,
which is also multiplied by their 72× transform: the effective stroke is
**360 px**, not 5 px. This expansion merges and clips the glyph outlines into
the heavy dark silhouette the reviewer liked, obscuring much of the specified
saturated fill. That appearance is intentionally preserved, not corrected
into conventional typography. Dark rounded background boxes use 55% opacity,
14 px padding and 16 px corner radius. Lane spacing is 260 px.

The companion `manifest.json` specifies 13-second scrolling durations with
1.5-second staggered starts. The PDF is the static SVG overlay, not a captured
animation frame. The label describes this distinction. Determinism checks
compare both the labeled SVG and the manifest across two emissions.

### Why original page 520 was blank

The original SVG contained only an HTML video inside `foreignObject`, which
does not become playable or visible video in the PDF renderer. The revised
example includes `examples/image/star-x-video-poster.png`, decoded from the
repository's existing MP4 at frame 7 (timestamp 0.338 seconds), when its star
is visible. Explicit frame selection avoids the blank blink phase in this
variable-timestamp clip. The
static poster is a native SVG image and is included by the raster verification
pipeline. The browser-facing video element remains; the PDF explicitly states
that it is a still frame.
