## Six ways to make the center move

| Motion system | Suitable references | Ten-second behavior |
| --- | --- | --- |
| Orbit and counter-rotation | Rosettes, medallions, orbital twins, roulette variants | Rotate the whole SVG group slowly around the frame center while an inner group counter-rotates; ease back toward its original orientation before the 7–10 s shrink. |
| Radial phase ripple | Fish-scale, sunburst, radial aperture, parallax moiré | Advance a radial phase through path coordinates or a parameterized SVG rerender; keep the central anchor fixed and cap displacement so the motif stays legible. |
| Breathing stroke | Bands, grids, flinque, sine curtain | Pulse stroke width and opacity in a slow, asymmetric rhythm, with neighboring line families slightly out of phase: the “cat purring” motion without moving the whole frame. |
| Bounded lattice drift | Linear grids, dot grids, wave bands, latent-image variants | Shift two transparent line groups by a few pixels in opposite directions, then return to register. Allow controlled moiré beats, while checking the phone proxy for flicker and aliasing. |
| Shape handoff | Compatibility, transition, and wild plates | Morph only paths with compatible topology; otherwise crossfade two SVG line groups while preserving a common center and proportional scale. Add a brief, bounded glitch or phase jump at the midpoint, then resolve before the exit. |
| Phase drift | Phase-variation rosettes, flinque, latent-image variants, radial and grid interference plates | During 3–7 s, slowly advance the relative phase of overlapping line families at slightly different rates, using source curve phase parameters or small relative rotations where appropriate. Let interference bands travel while the shared center and proportional scale stay fixed. Ease the drift to rest by 7 s and carry the resulting phase into the exit shrink. |

Use a fixed random seed to shuffle the selected plate order and assign motion
systems, and record that seed and the resulting order in a render manifest.
For phase drift, also record each line family's starting phase, drift rate,
and total phase sweep. Bound the rates using the full-size and phone-size
canaries so the moving interference remains readable without abrupt flicker.
Keep the first and last frame of every ten-second block centered so even a
hard cut between blocks has a coherent center-weighted rhythm. A short overlap
can be tested on a canary if a hard cut feels abrupt.
