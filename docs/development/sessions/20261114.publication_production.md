## Implementation

`scripts/build-publication.py` consumes an `izzi-publication-v1` manifest
through `izzi_publication.py`. It accepts hash-verified PDF, SVG and bitmap
assets, plain text, fonts, normalized visible-page crops and ordered chapters.
It reuses the existing `review_raster.py` SVG/font renderer. A dated JSON
profile holds physical and provider constraints; `portrait::print_spec`
continues to describe portrait mark construction rather than books.

The print path renders artwork at its placed 300 ppi size, converts sRGB
through an explicit CMYK ICC profile, and caps ink at 240% while preserving
K. It retains live 10.5 pt body / 9.5 pt source text, embeds fonts, and lays
out A4 pages with mirrored 20/15 mm inner/outer margins. Long keys use two
columns with row heights that follow the longest label. Ghostscript makes
PDF/X-3:2002 with a CMYK output intent; pikepdf and an independent placement
review check actual PDF contents rather than relying on the declaration.

EPUB uses reflowable XHTML and bounded RGB images, a navigation document,
source links, alt text and a separate 1400 x 2240 JPEG cover. EPUBCheck must
pass. Full-page mobile rasterization remains a distinct exporter: one opaque
RGB image per page, adaptive Flate/JPEG encoding and linearized PDF 1.4.
Cartofreako's old mobile CLI delegates to this implementation. Its completed
80-page mobile artifact and historical receipt are preserved unchanged.

Notable correctness fixes exercised by fixtures include cropped/rotated PDF
frames and UserUnit; Poppler's pre-rotation scale axes; explicit Unicode
fallback fonts; and ReportLab's image cache collision for identical raw
pixels with different dimensions. Unique image filenames preserve geometry.
The content adapter's audit caught nested source and observer sections,
groundstation aperture keys and fallback legend text that a shallow SVG
walk would have missed. Those domain-specific fixes remain in Cartofreako.

files without a receipt; these are rejected as incomplete on the next run.
