### Confirmed causes and limits of the earlier checks

- **Backward dog:** the actual MOSS prompt requested a body facing right and
  a head turned back left. The generated neutral asset follows that request.
  Returning the mesh to zero therefore returns to a backward-looking dog.
- **Unicorn mouth:** the selected jaw mask occupies approximately source
  pixels `x=586–608, y=147–172`, covering the muzzle tip beside the nostril.
  Visual inspection supports the user's complaint. Repositioning must follow
  an anatomically readable lip/jaw boundary, not another guessed nose anchor.
- **Short steps:** the compositor deforms a single static pose. Its nominal
  horizontal foot excursions at output scale are only about 14.88 pixels for
  unicorn, 12.65 for dog and 11.53 for cat. These are configured excursions,
  not measured Stage 4 stride lengths. Small knee motion and fixed source-pose
  offsets compound the weak gait.
- **Scenery discontinuity:** the crop uses `local = t - plate.start_seconds`,
  panning at 12 pixels/second. Different source-patch plates enter at 6 and 21
  seconds, restarting their crop position with a half-second crossfade.
  One global frame counter does not make those scene coordinates continuous.
- **Misleading evidence:** nonfolding meshes, attached mouth layers and
  measured head-angle changes establish technical properties. They do not
  establish correct anatomy, planted feet, readable gaze or an accepted
  performance. Those claims require viewing the actual moving result.

## 4. Plan A labeling instructions

### Deliverables for each sample

Save the source reference, context clip, animal crop, per-frame masks,
annotation JSON/CSV and an overlay video that displays the labels. Keep
original pixels separate from overlays. Use lossless diagnostic intermediates
where practical; review MP4s are derivatives. Record the exact crop-to-source
transform for every frame. A moving crop must not silently erase root motion.

Use a stable ID such as `dog_walk_forward_j002_f0120-f0200_v001`;
the numbers here illustrate naming and are not a selected good interval.
All ranges are half-open. Record source hash, native fps, provider frame range,
episode frame range, extraction command, crop dimensions, annotator, revision,
review status and parent revision. Never overwrite reviewed labels in place.

Each sample has three distinct label levels:

1. **Clip description:** animal identity, visible action, view, travel direction,
   camera movement, speech/attention state, visibility and defects.
2. **Events and intervals:** stance/swing, contacts, cycle boundaries, gaze
   entry/hold/return, blink, speech activity, glide/flap and occlusion spans.
3. **Per-frame observations:** anatomical points, masks, root/body scale,
   local ground contacts, head/eye direction and confidence/visibility.

### Controlled description fields

| Field | Values or instruction |
| --- | --- |
| `animal_id`, `speaker_id` | `unicorn/1`, `dog/2`, `albatross/3`, `cat/4`; no additional speaking identities |
| `action` | `walk`, `stand`, `transition`, `glide`, `flap`, `blink`, `speak`, `glance_speaker`, `glance_wildlife`, `return_forward`; allow simultaneous actions as separate tracks |
| `view` | Left/right profile, three-quarter front/rear, frontal, or changing; do not label an image-plane tilt as a genuine head-view turn |
| `travel_direction` | Measured screen vector and route-forward relation; “right” is a screen direction, “forward” is relative to travel |
| `head_relation` | `forward`, `toward_speaker`, `toward_wildlife`, `backward`, `unclear`; label observed state, not prompt intent |
| `gaze_target` | Speaker ID, `route_forward`, flock ID or `unknown`; do not infer eye contact from head angle alone |
| `speech` | `active`, `silent`, `uncertain`; separately record canonical speaker/audio time and visible mouth activity |
| `camera_motion` | Static, pan, translation/parallax, zoom, cut, or uncertain; store measured transforms separately |
| `visibility` | Visible, occluded, out of frame, or ambiguous for each point/limb |
| `quality` | Usable reference, needs correction, or negative example, with a specific reason |

Describe what is actually visible. Example description template:
“Dog, rightward travel, near forepaw planted then swinging, head forward,
mouth closed, torso steady, background moving left; far hind paw occluded.”
Only use that description when the clip supports every part. A backward head
is labeled backward even if the generation prompt called it conversational.

### Anatomical points and movement types by animal

| Animal | Points and parts to label | Motion examples to collect |
| --- | --- | --- |
| Unicorn | Withers/shoulder, hip, neck base, poll, eye, nose tip, nostril, lip line/mouth corner, lower jaw; near/far fore and hind leg joints, fetlocks/hooves; horn base/tip, mane and tail base | Clear equine walk cycle with hoof contact order, stance and swing, weight shift and head stability; forward neutral; modest partner glance/return; separately authored lower-jaw speech test |
| Dog | Shoulder, hip, neck base, eye(s), nose tip, upper/lower lip and jaw hinge; elbows/wrists, knees/hocks, four paw contacts; ears, collar and tail base | Natural canine walk, forward neutral, small listener glance/return, transition into/out of walking; speaking and closed-mouth pauses using the better local speech reference |
| Albatross | Torso/root, neck base, eye, upper/lower bill and hinge; near/far wing shoulder, elbow, wrist and tip; tail and visible feet | Stable glide, full wingbeat if present, flap-to-glide transition, head-forward and modest glance/return; bill opening independently of whole-head motion |
| Cat | Shoulder, hip, neck base, eyes, nose, mouth/jaw; near/far fore/hind joints and paws; ears, whisker roots, tail base/tip, emblem position | Feline walk and tail follow-through; forward neutral; brief upward flock tracking/return; silent mouth. Cat speech remains a separate later test |

Use anatomical near/far limb identities in profile, not ambiguous “left leg”
labels. Keep those identities across crossings. If side identity is uncertain,
mark it uncertain and exclude that section from contact/cycle fitting.
Do not invent hidden joints or assign confidence to guessed foot contact.

For each visible limb, label `contact_on`, `contact_off`, `stance`, `swing`,
contact location and cycle phase. Start phase zero at a specified repeated
event, such as near forepaw touchdown. Record the observed contact order;
do not force horse, dog and cat into the same sequence or cadence. For the
bird, use wingbeat/glide phase; omit ground-contact labels during flight.

Start with roughly 8–12 informative keyframes per cycle, including every
visible touchdown/lift-off, mid-stance, swing apex and crossing/occlusion.
