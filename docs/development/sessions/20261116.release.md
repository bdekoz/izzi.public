## Release preparation corrections

Full builds exposed two existing warnings treated as errors:

- GCC rejected the runtime unsigned-int height initializer for a `double`
  viewport in `examples/visualization-radial-kusama-swarm-round2.h`.
  Floating-point literals retain the same dimensions without narrowing.
- Clang rejected misleading indentation around the loop/switch in the
  video-glitch XML escape helper. Explicit braces preserve its substitutions.

These corrections retain rendering behavior and keep warning enforcement
enabled. Existing compiler and film/video tests exercise the affected paths.

The resource split check also found six tracked Fuller reference/example
assets under the host-local `resources.rincon/` tree. They were moved with
100% Git rename similarity to `resources.static/buckminister-fuller-archive/`;
the two referencing guides now link there and record the relocation. Other
host-local files remain in place, and `resources.rincon/` is ignored alongside
the other hostname sidecars.

The current header-migration receipt still described 46 headers and four
fragments. Refreshing this source inventory records the released 80 headers,
nine fragments and current source/build hashes; all canonical-prefix blocker
counts remain zero. Historical migration receipts remain intact.

The graph-characterization comparison found only an outdated byte count and
SHA-256 for `examples/visualization-radial-kusama-swarm-countries.h`. Only those
two provenance fields were refreshed, after asserting equality of every other
field. Legacy SVG/PNG evidence, graph geometry, MMRL data and authority fields
are unchanged.

The isolated release-test virtual environment includes system packages plus
CairoSVG 2.9.1, cairocffi 1.7.1 and cssselect2 0.10.1. This supplies the existing
danmaku and film-adapter tests without changing system Python packages.
Ignored local aliases restore the recorded danmaku resource layout. The
complete 283-page guilloche PDF was located and matched the recorded SHA-256,
`8df08d12aa75f57cbe8576a5d1de56fb6cf52f1573bbb39bd4de198a444209e0`, before
being linked at the expected test path.

The Dutch script font and all glyph/specimen artifacts rebuilt byte-identically.
Only the coverage receipt's Python version differed (3.14.8 versus 3.14.10).
The font test now compares stable coverage/provenance fields to the committed
receipt, validates the actual runtime version, and builds a second time to
require byte identity for every artifact including the runtime-bearing receipt.
Committed font and visual assets are unchanged.

Both Debug native-catalog checks hit their former 300-second timeout during
the complete Cartesian muqarnas grid. Their allowance is now 900 seconds;
all form/control/grid assertions remain enabled.
