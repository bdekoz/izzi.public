- Added `src/izzi-svg-reference-motion.h`. Guilloche motion changes native
  resolved paths, stroke widths, opacity, and line-family placement before
  SVG serialization. Moiré motion changes the native family recipe before
  resolving paths. The six motion systems include persistent phase drift.
- Circles retain a center and radius. Rotated filled rectangles carry all
  four corners as polygons, preserving their proportions.

  generators. All **64 baselines match** the catalog artwork geometry;

  reconstruction and background removal.
- The renderer uses native SVGs for the middle movement and caches parsed
  SVG DOMs for uniform entry/exit scaling. Every frame renders its vector
  DOM at the current transform through the same path. It rasterizes at 2160 × 3840,

  RGB `(230,230,230)` PNG. It checks every frame for exact gray wherever
  artwork and title alpha are zero.
- The catalog generators themselves are unchanged. The new motion API is
  opt-in. `tests/reference-motion.cc` checks zero motion, circle radii,
  rotated rectangle lengths/right angles, and phase persistence.

  included in `make movement-check`. That gate and the header's standalone
  compilation gate both pass.
- `izzi::guilloche::render_svg()` now honors `stroke_opacity` on normal
  paths as it already did on circles. Native motion resolves inherited ink
  opacity before applying a fade, so the first fade frame has no opacity
  jump. Existing default path output is unchanged.

### Correction found during final review

The first full render was marked **REVISE** and archived under
`attempts/01-recording-surface/`. A same-SVG, same-transform comparison found
that Cairo recording surfaces cached blended groups differently from direct
SVG rendering: page 111 differed at 133,033 pixels, with a mean absolute
channel difference of 0.8151. That created a visible change at the boundary
between entry/exit scaling and middle motion. Replacing those surfaces with
parsed SVG DOMs keeps the render path consistent for the whole plate.

The same review found that normal paths did not serialize their opacity.
Added that support and a regression check for inherited opacity, fade onset,
and the serialized attribute. The `guilloche` and
`movement.reference-parametric` tests pass. Native catalog identity is
checked again before the corrected render.

The corrected page 111 entry boundary measures 0.0109 mean absolute
channel change between adjacent frames. Direct-vector boundary checks also
cover pages 433, 449, 201, and 528. The final verifier compares the actual
master frames at both ends of those movements with fresh native SVG renders.
