# Fuller implementation record

Approved scope: Stages 0–8 of the September 20 archive report, across Alpha60,
cartofreako and Izzi. Output remains native C++ / SVG / HTML. Accessibility
target: [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/), with explicit checks and
unperformed checks recorded, not an unsupported conformance claim.

## Contract v1

Grain is collection key, observation interval, H3 cell/resolution, role and
metric. Keep H3 IDs as strings across browser boundaries. Geographic records
have both downloader and uploader slots; absent/null is unavailable, not zero.
Network memberships overlap. Legacy classification coverage is unknown even
when the historical producer wrote zero. Source selection policy is retained.
New union selection is OR, never an AND minimum on the two roles.

Transfer is separately collection-scoped: read `data_transfer` with decimal
GB/TB units, preserve the original value/unit and optional modeled prices.
The reviewed current derivation is payload size multiplied by corresponding
role counts, summed over the producer's deduplicated media objects; it is not
a packet/byte-counter measurement of completed transfers. Never apportion
collection volume to H3 cells. Joining requires matching collection and interval.
Combined title totals do not establish unique people or deduplicated traffic.

Stage 8 membership is frozen by the Japan-origin cohort manifest, not inferred
from peer geography or title text. Scenario inputs must distinguish observations
from hypothetical parameters. Missing prerequisites prevent stage completion.

## Reproduction

From the Izzi checkout, with a C++20 compiler, RapidJSON and H3 installed:

```sh
CCACHE_DISABLE=1 cmake -S . -B build/fuller -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_TESTING=ON \
  -DIZZI_CARTOFREAKO_SOURCE=/home/bkoz/src/cartofreako \
  -DIZZI_ALPHA60_SOURCE=/home/bkoz/src/alpha60
CCACHE_DISABLE=1 cmake --build build/fuller --target \
  izzi_fuller_studies izzi_fuller_form_plates izzi_fuller_swarm \
  izzi_fuller_cartofreako izzi_geojson_matrix_render izzi_count_share_matrix -j 2
build/fuller/izzi_fuller_form_plates outputs/fuller-form-plates
python3 scripts/build-fuller-studies.py --output outputs/fuller-studies \
  --renderer build/fuller/izzi_fuller_studies
ctest --test-dir build/fuller -R 'fuller\.|visualization.count-share-matrix' --output-on-failure
python3 tests/fuller-artifacts.py outputs/fuller-studies outputs/fuller-form-plates
node tests/fuller-browser.mjs outputs/fuller-studies outputs/fuller-studies/verification
node tests/fuller-browser.mjs outputs/fuller-form-plates outputs/fuller-form-plates/verification --plates
```

The plates do not require the other repositories or H3. The study builder reads
the local annual result repositories and the animation cohort receipts. Decoded
weekly inputs occupy approximately 13 GB; the renderer streams past nested
per-media foreign members and uses only the aggregate root features. No IP-level
records are read or exported. Chrome checks require a locally runnable Chrome;
the restricted environment used for this implementation required escalation to
start it. The `--no-sandbox` browser test uses only these generated local pages.

The same supplied contract, paired roles, hierarchy, histories, forms and bounded
global model run for each study. The combined Kong page keeps two title identities
and intervals; it does not merge peers. Japan-origin means work membership, not
Japanese peer locations. All study sums are explicitly sums of title measures.
The geographic sample is six retained cells per title, selected once by maximum
role size; the downloadable role JSON retains **all** source features.

Weekly transfer values are cumulative **through-week prefixes**, independently
derived from per-media payload GB × role counts in `collection_week_by_btiha`.
They must not be summed across weeks, treated as weekly increments, or forced to
equal independently produced terminal summaries. The producer call explicitly
uses incremental accumulation; legacy producer-version signatures are not
invented. Geographic histories use actual source start dates, not release dates.

## Verification

Focused checks cover missing/null versus zero, uploader-only rows, exact H3 string
identity, malformed counts, joins, units, common scales, cumulative-difference
compatibility, Euler/edge incidence, connected non-overlapping nets and scenario
balances. Eight affected public headers compile independently. The existing
count/share matrix test and cartofreako network-swarm generation test also pass.
Alpha60's isolated `a60-test-swarm-visual-contract` passes; this is not a claim
that the full production exporter was compiled.

`fuller-artifacts.py` independently reconciles every exported role count and all
parent sums/coverage with the original source features, checks payload-weighted
prefixes, scenario balances, legacy cost formulas, local links and SVG XML.
The real-input run reconciled **791,072 role records**. The plate run checked all
45 SVGs and 90 browser layouts (two widths per plate) without runtime exceptions.
`fuller-browser.mjs` records checks and screenshots at 1440 and 390 CSS pixels.
Plate checks include SVG text bounds, actual geometry and page overflow. Study
checks include linked selection, title filters, projections, map/grid registration,
scenario controls, unique IDs, anchors, minimum control dimensions and reduced
motion, plus named map/matrix buttons in Chrome's accessibility tree. Receipts
are in each output directory's `verification/browser-checks.json`.

Accessibility uses native controls, focus indication, a skip link, semantic
headings, live selection text, independently scrollable diagrams/tables, exact
values, SVG titles/descriptions and a no-animation path. The WCAG 2.2 AA target
does **not** imply full conformance: screen-reader/assistive-technology review and
a complete criterion-by-criterion audit have not been performed.

The Data visualization/validation skills informed source reconciliation, explicit
missingness and the evidence record. The user's C++/SVG/HTML requirement takes
precedence over the skills' default application stack. Existing unrelated
worktree edits and baseline-generation work have been left untouched.
