Detailed Description

Horizontal categorical bars and vertical numeric histograms.

This header provides two deliberately separate bar-shaped visualizations:

  • emit_bar_graph renders a horizontal categorical comparison from visualization_document::bars. Each categorical_bar::label is placed on the vertical axis and its nonnegative value is encoded as length on a zero-based horizontal axis. Input order is preserved, so callers may supply a meaningful sequence or a pre-sorted ranking. Horizontal bars are the better fit for named categories and long labels. See examples/visualization-bar-graph-horizontal.cc.
  • emit_bar_histogram renders a vertical numeric distribution from visualization_document::bins. Each histogram_bin supplies the numeric interval [left, right) and its nonnegative count; the final interval may include the maximum. Bar position and width come from the numeric x domain, while height encodes count on a zero-based y axis. Callers are responsible for binning source observations before render. See examples/visualization-bar-graph-vertical.cc.

Both emitters use the shared visualization title/description accessibility contract. Non-finite values, negative values/counts, and malformed histogram intervals are not rendered.
