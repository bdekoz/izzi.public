Detailed Description

Visualization fields aggregated from alpha60-swarm-metadata v2 records.

Counts are occurrences in identity.cast_leads[].ages, not distinct people or canonical works. Partial numeric ranges such as 40-45 are normalized to the corresponding decile (40-49) used by the chord layout. Actor-side nationality values are flattened separately for country visualizations.
