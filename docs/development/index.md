# Development notes

The `docs/development/` directory holds exploration notes and plans. There is
no single parent index file; the current entry points are:

- [Exploration notes index](explore_futures.md)
- [Milestone 0 baseline](milestone_0_baseline.md)

Daily exploration notes are named `explore_futures.<date>.md` (for example
[`explore_futures.20260812.md`](explore_futures.20260812.md)); restart and
plan pointers are named `explore_futures_*.md`.
